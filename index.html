Settings & Configuration

🔒 Privacy & Scope Setup (Restricted to ONE Folder only): In Google Cloud Console under OAuth consent screen > Scopes:
  • DO NOT select .../auth/drive (that requests full drive access).
  • DO SELECT https://www.googleapis.com/auth/drive.file. This officially restricts the app so Google allows it to see ONLY files it creates in its own folder. It is completely blind to the rest of your Google Drive.
Leave Folder ID blank to automatically create and use the dedicated Kreier-ToDo folder.

Select Google Drive Storage Folder

Choose where your ToDo database (kreier_todo_data.json), receipts, and imported notes will be stored. The app will operate strictly within this folder.
